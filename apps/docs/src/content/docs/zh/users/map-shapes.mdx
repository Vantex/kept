[位置地图](/zh/users/location-map/)能绘制的每种形状，按形状选择器显示的分组列出。每种形状都有图片、尺寸（宽 × 深 × 高，转向之前），以及在**查找形状**中找到它、或根据名称为物品指定形状的用词。本页依据 Kept 自带的形状目录生成，因此列出的正是你的 Kept 版本所拥有的形状。

尺寸是典型值，单位为厘米：物品在地图上保持其形状的尺寸，无论实际大小如何。当**单位**设为**英制**（设置 → 我 → 显示）时，地图以英尺和英寸显示尺寸，书柜卡片也用英寸；无论何种设置，Kept 始终以厘米保存。有两种形状按卡片上的参数定尺寸：**方块储物**按横向与纵向的方块数（每格 33 cm、深 39 cm：2 × 2 为 77 × 39 × 77 cm，4 × 4 为 147 × 39 × 147 cm），以及**高书柜**按宽、深、高和层数。此处显示的尺寸是它们的初始尺寸。带隔间的家具按自身尺寸绘制：隔间画在家具内部。用机柜模板制作的机架，会绘成其单元上方最近的服务器机架，设备放在对应单元上。

**缺少某种形状？**[提交请求](https://github.com/keptinventory/kept/issues/new?template=shape-request.yml)（需 GitHub 账号）：说明它是什么、给出尺寸，并附上照片或链接。或者[自己添加](/zh/developers/add-a-shape/)。
