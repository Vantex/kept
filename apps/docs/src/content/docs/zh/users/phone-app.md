Kept 没有应用商店应用。它是从浏览器安装的网页应用（PWA）：从自己的图标全屏打开，在手机上保留一份库存副本，并可离线工作。本页所有内容都要求 Kept 运行在 **HTTPS** 上：普通 HTTP 会阻止手机的摄像头、安装、推送通知与定位（[HTTPS](/zh/install/https/)）。

## 安装

首页清单上的**在手机上安装 Kept**，以及**帮助 → 在手机上安装**，会显示针对你设备的步骤：

| 设备 | 步骤 |
|---|---|
| iPhone、iPad | 在 Safari 中点按**分享**，然后**添加到主屏幕**，再点**添加**。从新图标打开 Kept。 |
| Android | 打开浏览器菜单（三个点），点**安装应用**或**添加到主屏幕**，然后从新图标打开 Kept。 |
| 电脑 | 在 Chrome 或 Edge 中，点地址栏末尾的安装图标，或菜单中的**安装 Kept**。Mac 上的 Safari 用**文件 › 添加到 Dock**。 |

首次从图标打开 Kept 时，清单步骤会自动勾选。新版本就绪时，Kept 会显示**新版本已就绪**并带**重新加载**；在上传或拍摄进行中绝不会自动重新加载。

## 离线时什么可用

手机保留你所属每个位置的副本，每次同步时刷新。离线回答会标注**截至上次同步**及时间。

| 离线可用 | 需要连接 |
|---|---|
| 浏览位置、房间、箱子与物品 | 编辑物品详情、设置、管理 |
| 搜索，标注为**本机** | 助手与 AI 命名 |
| 拍摄、移动、标记已见、不在此处 | 导入、导出与报告 |
| 记录读数、添加房间或点位 | 记录保养（涉及金额） |
| 箱子核对，针对曾在线打开过的箱子 | 任何涉及金额或机密值的内容 |
| 扫描标签、认领空白标签 | |

副本从不包含机密值或人员的联系方式。除非你在应用锁后为某位置保留离线（见下），金额与文档不会上手机。登出会在手机上删除此人的副本。

## 同步，在你看来的样子

你离线时做的事会进入队列，在手机恢复联网后发送。标题下的一行只在有内容时出现：

- **离线，12 项待同步**，或**离线，截至上次同步，14:02**。
- 新物品在服务器分配短 ID 前显示 **ID 待定**；ID 到达后可打印其标签（标签页提供**打印待定标签**）。
- **在 iPhone 上，队列仅在 Kept 打开时前进**：该行显示 **打开以完成同步 (12)**。恢复联网后让 Kept 在屏幕上停留片刻。
- **更新 Kept 以完成同步**表示服务器比应用新：请重新加载。队列会保留。
- **此浏览器可能在闲置数周后清除 Kept 的离线副本**：手机拒绝了 Kept 的永久存储。偶尔打开 Kept 以便同步。

**当某项更改无法应用。** 若你离线期间他人把某物品移入回收站、移动或移除，你对它的更改会被丢弃，该行会说明，例如“有一项更改无法应用：电钻已被 Alfred 移入回收站”，并带**恢复**以重试。其他需要决定的更改进入**收件箱**（“2 项更改需要查看”）。

**当你与他人在网上同时编辑同一件物品**，Kept 只合并其中一方改过的字段，其余会询问：**保留我的**、**保留对方的**或**编辑**。

**带着未发送的拍摄登出**会先警告：登出会删除尚未同步的拍摄。若会话过期，手机会丢掉你的库存副本，但保留未发送的拍摄并锁定，直到你重新登录。若他人在该手机上登录，Kept 会说明有多少拍摄在等待另一个账户，并仅在对方同意后删除。

## 摄像头、图库与扫描

- **拍摄**让摄像头保持打开，可连续拍摄。**图库**一次选多张照片；每张成为一个草稿。若摄像头被阻止，Kept 会说明如何允许；普通 HTTP 下拍摄会回退为选择文件。
- iPhone 的 HEIC 照片按原图保留；若某张无法预览，会显示**无法预览**，绝不拒绝。
- **分享到 Kept：**在 Android 与桌面 Chrome 上，已安装的应用会出现在分享面板中，因此来自其他应用的收据或 PDF 可落入拍摄。iPhone 不允许网页应用出现在分享面板：先保存文件，再在拍摄中使用**图库**。
- **扫描**读取 Kept 标签与商品条码，也可离线（来自手机副本），以及 Data Matrix、Code 39、Code 93、ITF、Codabar、PDF417 与 Aztec 代码；联网时序列号或资产标签会打开其物品。完整列表：[短 ID 与标签](/zh/users/everyday-use/#short-ids-and-labels)。
- **建议我的位置**（拍摄的位置选择器中的开关）在手机本机比较你的位置与各位置的位置，并建议你所在的那个：在其位置 150 米内，两个都满足时取更近的。你的位置从不发送或保存。所有者或管理员在**位置设置 → 常规 → 位置**中设定位置的位置（[其位置](/zh/users/locations/#its-position)）；没有位置的位置从不被建议。
- **听写**在浏览器支持处用语音填写名称。

**设置 → 诊断**检查摄像头、离线支持与存储，并复制一份检查结果报告。

## 应用锁

**设置 → 此设备 → 应用锁**用 6 至 12 位 PIN 锁定手机上的 Kept，并在手机能验证你时支持**用 Face ID 或指纹解锁**。锁开启后，Kept 会在冷启动以及隐藏或闲置 5 分钟后询问，联网或离线皆然。

这里的 Face ID 或指纹只解锁此设备上的 Kept；绝不为你登录。要用 Face ID 或指纹登录，请在[登录与安全](/zh/users/sign-in-security/)中添加通行密钥。

- 连续输错十次 PIN 会从此手机删除 Kept 的副本并让你登出，保留你自己的未发送拍摄。**忘记了吗？登出后重新登录**效果相同。
- 锁能挡住拿着手机的人。它挡不住已复制浏览器存储、正在尝试 PIN 的人；设置页会说明这一点。

同一页上的**保留离线可用**会把某个位置的价格与文档加入手机副本，加密置于锁后。它需要应用锁开启，会先显示下载大小，并警告在手机上解锁 Kept 的人能看到它们。一台设备最多以此方式保留 250 MB，单个文件最大 25 MB。

## 通知

在**设置 → 我 → 通知**下，**此设备**中的**启用**会打开推送：即使 Kept 已关闭，提醒也会弹出。**测试**会发一条以供检查。

- **iPhone 与 iPad**只向已安装的应用推送：把 Kept 加到主屏幕、从那里打开并启用。在此之前，提醒可通过邮件送达。
- 推送需要 HTTPS。若服务器无法发送推送，或浏览器无法接收，页面会说明；邮件与通知中心仍可用。
- 免打扰时段会把推送与邮件扣到时段结束。各位置发送什么、如何发送，见[日常使用](/zh/users/everyday-use/#reminders-and-notifications)。
