Kept 能做的一切，每项都附上说明页。部分功能属于**模块**：位置在**位置设置 → 要跟踪的内容**中开启（[模块与预设](/zh/users/modules/)）。模块在其适用的功能处命名。

## 清单

- **[位置、房间与箱子](/zh/users/locations/)**：住宅、车库、储物间；位置中的位置。移动箱子，里面的东西也跟着移动。可展开或折叠的位置树。
- **[隐藏 Personal](/zh/users/locations/#hide-personal)**：把你的 Personal 位置从菜单、首页、列表和搜索中移除，随时可再显示。
- **[位置的位置](/zh/users/locations/#its-position)**：从手机设置或手动输入，使拍摄时能建议你所在的位置。
- **[带隔间的家具](/zh/users/locations/#furniture-with-compartments)**：格子架或抽屉柜，每个隔间是独立位置。可侧放、合并或拆分隔间；标签继续有效。
- **[机架](/zh/users/locations/#racks)**：按机架单位（U）计量的服务器机架，页面和地图上显示哪个单元放了什么。同一单元放两件、或超出顶部会被拒绝。
- **[物品](/zh/users/things/)**：类型、自定义字段、数量、状况、归档，以及可恢复的回收站。
- **[照片、收据、说明书与保修](/zh/users/photos-paperwork/)**：放在每件物品上，并有文书库；文件保留你选择的名称。模块：收据与保修、文书。
- **[购买记录](/zh/users/things/)**：物品何时何地购买、价格、收据总计与税费，以及其收据，从物品页面编辑。
- **[房间照片](/zh/users/room-photos/)**：拍摄房间、柜子或架子；Kept 会列出其中内容作为草稿供你确认。需要 AI 提供商。
- **[表格视图](/zh/users/spreadsheet/)**：一次处理多件物品，在表格中编辑。
- **[搜索](/zh/users/search/)**：名称片段、序列号、收据文字；每条匹配在哪里。
- **[标签](/zh/users/tags/)**：跨位置与类型。

## 找到物品

- **[位置地图](/zh/users/location-map/)**：每个位置的 3D 图，含楼层、按真实尺寸（50 cm 起）的房间、家具及其隔间，以及里面的东西。有平面图时可从平面图开始。尺寸用米或英尺英寸。
- **[关系图](/zh/users/graph/)**：位置中位置、箱子与物品的 2D 或 3D 关系图。
- **[短 ID 与标签](/zh/users/short-ids/)**：每个箱子一个短 ID 和二维码；扫描即可打开。标签机卷纸或办公纸张。模块：标签与二维码。
- **[扫描会话](/zh/users/scanning-sessions/)**：盘点货架、装箱、搬动一堆，一次接一次扫描。
- **[盘点与清点](/zh/users/counts/)**：盘点某处、看缺了什么、与上次盘点对比。

## 家庭事务

- **[借用与出借](/zh/users/lending/)**：谁持有什么、何时归还，带提醒和可复制的礼貌消息。借用者无需账户。每件物品按顺序显示谁持有过、如何归还以及谁收回。模块：Lending。
- **[套件与交接](/zh/users/kits/)**：借出一个箱子及其中所有东西；每件物品各自有记录。套件会记住里面应该有什么。
- **[搬家](/zh/users/moving/)**：编号箱子、每箱的标签与内容清单、在货车中跟踪、扫描拆箱。可离线使用。模块：搬家。
- **[提醒与通知](/zh/users/reminders/)**：保修、保养、文件、借用与低库存，通过应用、邮件、推送、ntfy、Telegram 和日历订阅。模块：提醒。
- **会用完的物品**：每件物品设最低数量；快用完时通知。模块：会用完的物品。
- **[车辆与机器](/zh/users/vehicles/)**：读数、保养、燃油与运行成本。里程表用 km 或 mi，可用“更改单位”重新标注或换算读数。模块：车辆、燃油。
- **密码与验证码**：机密字段，需被允许才能显示，且会记录日志。模块：密码与验证码。
- **[状况报告](/zh/users/condition-reports/)**：入住与退租，按房间，含照片。
- **[报告、保险与理赔](/zh/users/reports/)**：PDF 清单、保险报告、理赔包。
- **[洞察](/zh/users/insights/)**：按年份的花费与按位置的价值，每种货币分别统计。模块：金钱与花费。

## 人员

- **[共享位置](/zh/users/sharing/)**：邀请带角色（管理员、成员、查看者）和可选结束日期的人员；为无邮箱者提供托管账户；为无账户者提供只读分享链接。
- **[登录与安全](/zh/users/sign-in-security/)**：通行密钥与两步登录；家庭网络上用普通 http 时，[登录时长由管理员设置](/zh/install/home-network/#staying-on-your-network)；一个 Kept 可以[使用多个地址](/zh/install/home-network/#more-than-one-address)，例如局域网名和 Tailscale 名。
- **语言**：阿拉伯语（从右到左）、英语、法语、德语、意大利语、西班牙语、乌克兰语和越南语；在选择器中输入即可找到你的语言，日期按你所在地区风格或由你选择。金额按你的语言书写方式读取。PDF、理赔包和可读副本都用你的语言输出。用户、管理员和安装文档也提供各种语言。

## 在手机上

- **[手机上的 Kept](/zh/users/phone-app/)**：从浏览器安装；无信号时也能拍摄、扫描和搜索，稍后同步。

## AI（可选）

- **[AI 提供商](/zh/users/ai-providers/)**：自备提供商或不使用：OpenAI、Anthropic、Google、OpenRouter、Groq，或本地服务器如 [Ollama](/zh/admin/ollama/)。拍摄会根据照片起草物品；由你确认。
- **助手**：用平常的话提问；改动等你确认。
- **[Claude 及其他 AI 应用](/zh/users/mcp-clients/)**：位于 `/mcp` 的 MCP 服务器；已连接的应用会保持连接直到你撤销。模块：连接 ChatGPT 或 Claude。

## 可与之配合

- **[Home Assistant](/zh/users/home-assistant/)**：Kept 作为 Home Assistant 应用，以及用于仪表盘、自动化和日历的集成。应用会在 Home Assistant 中提供集成；你在 Kept 中允许即可，无需复制令牌。
- **[Paperless-ngx](/zh/users/paperless/)**：链接文档而不是复制它们；在 **Link from Paperless** 中输入词首即可找到。[Homebox 导入](/zh/users/import-export/)会从 Paperless 取其链接标题。
- **[仪表盘](/zh/users/dashboards/)** 与 **[webhooks](/zh/users/webhooks/)**：为你的仪表盘提供摘要；事件发送到你自己的服务。
- **[导入与导出](/zh/users/import-export/)**：来自 Homebox、表格（CSV）或另一个 Kept；车辆历史可来自 LubeLogger；完整导出。

## 运行与维护

- **[备份](/zh/admin/backups/)**：每晚、加密，到目录、S3 或 SFTP，每份都附带[无需 Kept 即可打开](/zh/admin/read-with-restic/)的副本。
- **[系统需求](/zh/install/hardware/)**：一个容器和 Postgres；已在 1 GB 内存和单核 CPU 上测试。
- **[安全模型](/zh/admin/security-model/)**：无遥测；除非你开启，否则不会有任何数据离开服务器。
