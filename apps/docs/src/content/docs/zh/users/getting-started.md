title: 快速开始
description: "从零到在 Kept 中添加第一件物品的简短路径，每一步都附有详情页链接。"
---

简短路径，每行一步。每一步都链接到详情页。

1. **安装。** 需要带 Compose 插件的 Docker；已在 1 GB 内存和单核 CPU 上测试。下载 `compose.yaml`，然后执行 `docker compose run --rm init`（会询问你将打开 Kept 的地址并写入 `.env`），再执行 `docker compose up -d`。无需克隆仓库，也无需设置密码。[使用 Docker Compose 安装](/zh/install/compose/)
2. **认领服务器。** 打开地址，输入 `init` 显示的设置码，并创建第一个账户：它会成为实例管理员。
   [认领服务器](/zh/users/first-run/#1-claim-the-server-with-the-setup-code)
3. **保管好密钥。** 打印恢复套件，并放在服务器之外的地方。
   [恢复套件](/zh/admin/recovery-kit/)
4. **创建你的第一个家。** 起个名字、选择类型、房间，以及要跟踪什么的预设。
   [创建你的第一个家](/zh/users/first-run/#3-create-your-first-home)
5. **添加一件物品。** 手机上用**拍摄**，电脑上在房间或箱子上点**在此添加**。
   [添加第一件物品](/zh/users/first-run/#4-add-your-first-thing)
6. **邀请他人。** 通过链接或二维码，并指定角色（管理员、成员或查看者）；无需电子邮件地址。[邀请人员](/zh/users/first-run/#5-invite-people)
7. **启用 HTTPS**，这样手机才允许摄像头、安装 Kept、离线使用和推送通知。
   [HTTPS](/zh/install/https/)，或参见[家庭网络上的 Kept](/zh/install/home-network/) 了解无 HTTPS 时可用的功能
8. **连接 AI**（如果你需要）：没有 AI Kept 也能工作。[AI 提供商](/zh/users/ai-providers/)

接下来：[日常使用](/zh/users/everyday-use/)了解导览，[常见问题](/zh/users/faq/)了解常见疑问，出问题时看[常见故障](/zh/users/troubleshooting/)。
