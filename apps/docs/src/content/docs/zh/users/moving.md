**搬家**把家装进编号箱子，在另一端拆开。每个箱子都是普通的 Kept 箱子，因此你放进去的东西一路都可查找：搜索水壶，Kept 会显示**箱子 7**。在新家，扫描箱子的标签、选择房间，箱子及其全部内容会一次性移过去。

它在没有信号的手机上也能工作——搬家当天大部分时间如此。

![深色主题下的同一次搬家](../../../../assets/screens/moving-desktop-dark.webp)

## 开启

搬家是**完整**预设的一部分。对其他任何位置，所有者或管理员在**位置设置 → 跟踪内容**中开启**搬家**。它需要**标签和二维码**，每个预设都有。其条目**搬家**随后出现在侧边栏（手机上在**更多**下）。

## 1. 开始一次搬家

1. **搬家 → 开始一次搬家**。
2. 起个**名称**（“搬到新公寓”），以及**去向**：你的另一个位置；若只是重新整理，也可以是同一位置内的房间。

要搬到新家？先把它添加为带房间的位置，这样每个箱子可以直接进其房间。

## 2. 装箱

- **添加箱子**给出下一个编号：箱子 1、箱子 2，依此类推。若已知，现在就选择**去向房间**；它会印在装箱清单上，拆箱也从它开始。
- 从箱子页面装满它：**打开箱子**以添加物品或移入，或**用扫描器装箱**：扫描物品将其拿起，再扫箱子标签放入。
- **打印标签**为每个箱子打印一张标签（Kept 支持的任一标签纸）。贴在每个箱子上你会在堆叠中看到的那一面。
- **装箱清单**生成每箱一页的 PDF：编号、去向房间、内含物与代码。用胶带贴在箱子上；上面的代码与标签一样可扫。打印完成后，PDF 下方的**已打印？**会记录它，这些箱子的代码会显示为琥珀色标签胶带，与从**打印标签**打印的标签一样。

## 3. 在货厢中

箱子装车后**全部标记为运输中**，或从各箱子页面逐个标记。

看板以计数开头（**已装箱**、**运输中**、**已拆箱**），并列出**仍待拆**的箱子，这样你在另一端能看出哪些还没到。可按状态或房间搜索、筛选与分组箱子。

## 4. 拆箱

![手机上扫码拆箱：箱子 1，去向厨房，带“拆到厨房”](../../../../assets/screens/moving-phone-light.webp)

1. 在搬家中点**扫码拆箱**，把摄像头对准箱子的标签或装箱清单。（没有摄像头？**输入代码**同样可用。）
2. 去向房间已预先选好；需要的话可以改。
3. **拆到厨房**。箱子及其全部内容现在在新家的厨房里。立刻扫下一个箱子。

消息上的**撤销**会把箱子放回原处。每个箱子都拆完后，**标记搬家完成**；若某箱之后才到，用**重新打开**。

## 离线

在手机上，打开过一次的搬家会被保留供离线使用。没有连接时，你仍可查看看板与每个箱子的内容（截至上次读取时）、装箱、标记已装箱或运输中、选择箱子去向房间，以及拆箱。这些更改在手机上等待，立即显示，恢复联网后同步；等待期间消息上的**撤销**可收回某一项。

若两部手机在离线时改了同一个箱子：

- **已装箱、运输中、已拆箱：**后改的那部手机胜出，无论谁先同步。
- **去向房间：**后同步的房间胜出。
- **期间已拆箱的箱子**保留其被拆入的房间。之后为它选择的房间不会改变任何事：若它属于别处，请移动箱子本身。
- **期间被某人移入回收站的房间：**更改无法应用。收件箱会说明是谁移入的，并带**恢复**。

开始搬家、添加箱子、生成装箱清单与标记搬家完成需要网络连接。

## 从已连接的应用

以**读取与更改**连接的应用（ChatGPT、Claude：[连接应用](/zh/users/mcp-clients/)）可以开始搬家、添加箱子、装箱、标记运输中与拆箱，规则与撤销与本页相同。只读连接会列出搬家与箱子，以及仍缺哪些。

## 谁能做什么

| | 查看者 | 成员 | 管理员与所有者 |
|---|---|---|---|
| 查看搬家及其箱子 | 可以 | 可以 | 可以 |
| 生成装箱清单 | 可以 | 可以 | 可以 |
| 确认装箱清单已打印 | | 可以 | 可以 |
| 开始搬家、添加箱子、装箱、标记与拆箱 | | 可以 | 可以 |
| 删除一次搬家（其箱子保留为箱子） | | 可以 | 可以 |

拆到另一位置还需要你能在那边添加物品。每次更改都在箱子的历史与位置的活动中。

Kept 导出也包含搬家：每个箱子的编号、状态与去向房间，以及箱子与其全部内容作为物品所在的位置。导入后，去另一位置的搬家会变成新位置内的搬家，房间需重新选择（导出只含一个位置）。已拆到另一位置的箱子会作为物品出现在那个位置的导出中。
