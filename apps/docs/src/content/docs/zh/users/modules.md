每个位置都运行在一种**预设**上：一组同时开启的**模块**。预设只是起点：所有者或管理员之后可以单独开关各模块，关闭只是将其隐藏，不会删除任何内容。

创建位置时选择预设（[最初几分钟](/zh/users/first-run/)）。新账户的**个人**位置从基础预设开始。导入 Homebox 到新位置也从基础预设开始，并在此基础上勾选备份中有数据的各模块（[从 Homebox 导入](/zh/users/import-export/#a-homebox-export)）。

## 三种预设

- **基础**：查找物品：房间、箱子、标签与搜索。
- **家居**：增加收据与保修、提醒、借出、文件与车辆。
- **完整**：增加燃油、你已用完的物品、密码与代码、搬家，以及“连接 ChatGPT 或 Claude”。

时区与货币不属于预设：它们在**位置设置 → 常规**中。

## 各模块带来什么

下列名称是**跟踪内容**中的开关。

| 模块 | 来自 | 带来什么 |
|---|---|---|
| **标签和二维码** | 基础 | 物品与位置的可打印标签；扫描标签会打开其对应对象。 |
| **金额与支出** | 家居 | 价格、合计与**洞察**。每种货币单独一行，从不换算。 |
| **收据与保修** | 家居 | 保修日期；即将到期的保修显示为提醒。 |
| **提醒** | 家居 | 计划任务：到期事项，按日期或按读数。 |
| **借出** | 家居 | 借出物品与借入物品。 |
| **文件** | 家居 | 文件库；文档日期会触发提醒。 |
| **车辆** | 家居 | 车辆与机器。 |
| **燃油** | 完整 | 燃油与充电。需要**车辆**。 |
| **你已用完的物品** | 完整 | 物品上的**至少保留**；低库存显示为提醒。 |
| **搬家** | 完整 | 搬家模式。需要**标签和二维码**。 |
| **密码与代码** | 完整 | 机密字段：在获准的人揭示之前保持隐藏，揭示会被记录。 |
| **连接 ChatGPT 或 Claude** | 完整 | MCP 连接，让 AI 应用可以操作该位置。 |

## 此位置中的 AI

只要为该位置连接了 AI 提供商，AI 拍摄与助手会在任何预设下开启。它们共用一个开关——同一页上**此位置中的 AI** 下的 **AI 拍摄与助手**，因此即使已连接提供商，位置也可以不使用 AI。选择预设不会改变这一点。参见 [AI 提供商](/zh/users/ai-providers/)。

## 关闭某个模块

关闭的模块在其本会出现在的所有地方（界面、菜单项、筛选器）都会隐藏，其提醒也会暂停。重新打开会带回一切，因为什么都没有被删除。

- **提醒随其模块暂停。** 计划任务与即将过期的物品等待**提醒**，保修与登记日期等待**收据与保修**，文档日期等待**文件**（**车辆**开启期间，车辆文档仍会继续运行），借出等待**借出**，低库存等待**你已用完的物品**。近期未读取的仪表提醒始终运行。
- **依赖项也会一并关闭。** 燃油需要车辆，搬家需要标签和二维码：关闭某模块所依赖的模块，该模块也会关闭。其开关会显示为 *需要车辆，此位置已关闭*。
- **菜单跟随你的全部位置。** 在**跟踪**下，某条目（计划任务、借出、文件、消耗品、车辆、搬家、洞察）只要在你的任一位置开启过就会显示。在**工具**下，**标签**只要某处开启就会显示，**盘点**则始终存在。活动、回收站与通知也始终存在。

## 之后更改

所有者或管理员打开**位置设置 → 跟踪内容**。预设选择器会一次设定全部模块；其下方的**精细调整**为每个模块各有一个开关。保存前，**保存时**会列出将开启和将关闭的内容。
