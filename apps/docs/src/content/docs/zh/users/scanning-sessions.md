**扫描会话**在你走动时保持摄像头打开。视野中的每个 Kept 标签都会被读取（一次多个），并只计一次。用途包括：

- **清点**房间、架子、箱子或整个位置：扫到的会被标记为已见，摘要会显示缺失了什么、以及有什么出现在别处。
- **装入**箱子：扫到的一切都进入当前箱子。扫下一个箱子即可切换。
- **移到**某个位置或箱子：扫到的一切都移到那里。

一个会话最多容纳 5,000 个标签；手机曾在线打开过会话后，即使无信号也能工作：界面在首次使用时获取，之后保存在手机上。

会话读取二维码与条形码。没有二维码的标签（窄条标签机胶带）改为在**扫描**中按其印刷短 ID 一次打开一个（[扫描没有二维码的代码](/zh/users/short-ids/#scanning-a-code-with-no-qr-code)）。

## 开始会话

- **扫描 → 开始会话**，然后选择要做什么、在哪里做。
- 从位置页面：**在此清点**。
- 从箱子菜单：**清点此箱**或**装入此箱**。
- 从搬家页面：**装箱**。
- 从地图上的房间卡片：**清点此房间**。

尚未选择位置时，从列表中选择，或点按**扫描其标签**。

清点某个位置时，**包含其中的位置**默认开启。若在不打开箱子的情况下清点它们，可开启**扫到的箱子会清点其内部**。

## 扫描时

| 你扫到 | 清点 | 装入、移到 |
|---|---|---|
| 列表中的物品 | 找到，绿色，计数增加 | 已加入，绿色 |
| 同一标签再次扫到 | 轻微勾选，不计数 | 同上 |
| 此处其他位置的物品 | 琥珀色：**在别处找到**，并显示应在何处 | 已加入 |
| 其他位置的物品 | 琥珀色，附位置名 | 两处都能编辑时才加入 |
| 你仅查看的位置中的物品 | 灰色：**此处仅查看** | 灰色，不加入 |
| 位置的标签 | Kept 建议从其自身页面清点 | 拒绝：房间不能被移动 |
| 空白标签，或多个物品共用的代码 | 留给摘要 | 同上 |
| 商品条码 | 匹配到承载它的物品 | 同上 |
| 序列号或资产标签（Data Matrix、Code 39…） | 联网时匹配到拥有它的物品 | 同上 |
| 此手机离线时未知的代码 | **稍后检查** | 同上 |

清点时计数显示“312 / 340”。每次读取会播放短促提示音并在标签上画出方框：新发现为绿色，别处为琥珀色，其他为灰色。

- **撤销上次读取**收回上一次。
- **暂停**停止摄像头。一分钟无读取也会暂停。
- **目标**（装入、移到）：点按它，然后扫下一个箱子或位置。
- **USB 或蓝牙条码扫描器**在同一界面工作：其输入会像标签一样被读取。
- **手电**在具备手电的手机上显示（Android）。

关闭应用、刷新页面或电量耗尽：会话仍留在手机上。**扫描 → 恢复会话**可继续。

## 完成并保存

**完成**显示摘要。此时还没有任何更改。

- **找到：**已标记为已见，时间取各标签被读取的时刻。
- **缺失：**默认保持不动。可逐个选择**标记不在此处**，或**全部标记不在此处**。
- **无标签：**列表中没有标签的物品。勾选你看到的那些。
- **在别处找到**与**在其他位置：**保持不动，或**移到此处**。
- **未匹配：**空白标签与匹配多件物品的代码。每个空白标签都有**认领**：新箱子、现有物品或现有位置。把空白标签贴在架子和门上，一次走动全部扫到，然后在这里认领。

清点还会列出借出中或维修中的物品（从不计为缺失），以及其中某位置内无人清点的内容（**未清点**，直到你点按**我检查过了**）。按数量清点的物品行上有 **−** 与 **+**。每个结果都会保存：参见[盘点与清点](/zh/users/counts/)。

**保存**发送该会话。离线时它在手机上等待，恢复联网后保存。会话在**活动**中是一条记录，“清点了车库：312 / 340”，并有 7 天**撤销**。撤销会恢复每个“已见”日期、每个“不在此处”与每次移动，除非此后已有更改。

走动期间被移入回收站的物品不会纳入保存，保存后的摘要会说明有多少件。

## 谁能做什么

| | 所有者、管理员、成员 | 查看者 |
|---|---|---|
| 清点 | 保存 | 检查：同一界面与合计，不保存 |
| 装入、移到 | 你同时能编辑物品及其去向时 | 不提供 |

若走动期间你的角色变更、不再能在该处编辑，保存会被拒绝，会话连同摘要留在手机上。

## iPhone 限制

- 无振动：网页应用在 iPhone 上无法振动。提示音与彩色方框表示每次读取。
- 已安装应用中屏幕仍可能变暗：大规模清点时在**设置 → 显示与亮度 → 自动锁定**中保持常亮。
- 较旧的 iPhone 上读取可能更慢。把手机离密集标签稍远一些，让视野中能容下多个。
- 网页无法控制手电。
