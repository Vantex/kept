---
title: 关系图
description: "把位置看作楼层、房间、箱子与物品的关系图，2D 或 3D，含需要关注的事项和你的标签。"
---

位置页面有五种布局：**List**、**Grid**、**Graph**、**Table** 和 **Map**。Table 仅宽屏可用，因此手机显示 List、Grid、Graph、Map。**Graph** 把位置画成节点与连线：位置本身、其楼层、楼层上的房间、房间里的货架与柜子、箱子里的东西，以及其中的物品。Kept 在每台设备上按位置记住你的选择。楼层或房间页面也有 **Graph**，会打开在该位置上。

关系图需要网络连接，与地图一样：它不在手机的离线副本中。只在你打开时加载。

## 2D

2D 关系图中间显示一个位置，周围两层：第一环是直接在其中的内容，第二环是其中的内容（空间允许时）。

- **大小**显示里面有多少：更大的节点装更多物品。
- 内容未画出的节点会显示其**数量**。
- **点选**节点查看其卡片。再**点选一次**，或卡片上的**进入**，可将其放到中间。
- 图上方的**路径**（Home › Ground floor › Garage）可向上返回。
- **Rooms、Boxes、All** 选择绘制深度：仅位置、位置与箱子，或一直到物品。

拖动移动关系图，滚轮或双指缩放，房屋按钮恢复显示整个位置。

## 3D

**3D** 一次显示整个位置：位置在上方，每层作为不同高度的一层，房间在其楼层周围一圈，其中的东西向外展开。没有楼层的位置就是一层。

在你触碰之前它会缓慢旋转；当设备要求减少动态效果时，它会保持静止。拖动旋转，滚轮或双指缩放。旁边的按钮可左右旋转、从更高或更低视角查看、缩放、开始或停止旋转，以及显示整栋房子。楼层按钮（与地图相同）把某一层带到前面；**All** 显示所有楼层。

点选节点会把其分支带到前面：外面的会淡出，并标明其中有什么。Kept 在每台设备上为你记住 2D 或 3D。

## 标记与标签

节点上的圆点用地图的颜色显示其内部需要关注的内容：**低库存**（红）、**已借出**（蓝）和**即将到期**（橙）。来源与地图标记相同：Consumables、Lending，以及日程、保修和文件。每个节点的无障碍名称也会读出（“车库，房间，9 件物品，1 件已借出”）。

开启 **Tags** 会把你的标签作为彩色芯片加上，每个链接到持有相应物品的位置与箱子。点选标签可列出携带它的内容。

## 卡片

卡片显示节点在哪里、是什么、里面有多少物品、其标记，以及里面有什么（可点选任一项）。**打开**进入其页面，**在地图上显示**打开地图上的它（或持有某件物品的位置），**进入**把它放到 2D 关系图中间。手机上卡片是底部面板；**×** 或 Escape 关闭。

## 用键盘或屏幕阅读器

每个节点都是按钮。Tab 按树顺序移动，Enter 选中，再 Enter 进入，Escape 关闭卡片并再上一级。图下方有一个显示内容的列表（供屏幕阅读器，Tab 进入时也会显示），作用相同。

## 大型位置

Kept 关系图最多绘制 2,000 件物品。超过后，其余在各自位置和箱子中计数但不绘制。3D 中，位置超过约 450 个位置点、箱子和物品时，只为你选中的分支绘制物品。
