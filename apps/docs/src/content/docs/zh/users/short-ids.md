新物品到达服务器时会获得一个短 ID：六个字母与数字，如 `7KQ-4MZ`，从不复用。在此之前显示 **ID 待定**。标签以文本承载该 ID，并在除窄标签机胶带外的每种标签纸上以二维码承载，点开即到该物品。标签永久保留其代码，因此丢失后可重印出相同代码。

列表、搜索结果与 ⌘K 面板按名称显示物品。其代码仅在已有印刷标签时才以琥珀色标签胶带显示：经**已打印？**确认的标签，或为其认领的空白标签。搬家的装箱清单经同样方式确认后也算数（[搬家](/zh/users/moving/)）。琥珀色表示“此件已贴标”。在其自身页面上，没有印刷标签的物品或位置会在其余内容之后以小号灰色显示代码；有标签的显示胶带。有多张标签的物品（例如为其认领的空白标签）显示最后印刷那张的代码。搜索与扫描器可用其任一代码找到物品。

## 打印

**打印**（菜单中的标签，或物品上的**标签**）：选择要打印什么（一个选择集、某位置或场所的**打印所有未印刷标签**，或**空白纸张**），选择**标签纸**，在已部分使用的纸上选择起始位置，然后从浏览器打印。**纸张预览**就是打印本身，只是更小：同样的二维码、名称与位置，同样的换行。名称从不截断：过长会折行且类型变小，仍放不下的会在打印前列出并附重命名链接。页面按纸张尺寸无页边距设置，因此打印对话框的默认值（缩放 100 %）会把每个标签放进其格子。

标签纸（在设置 → 我 → 显示中把**单位**设为**英制**时，选择器以英寸显示这些尺寸，保留两位小数：Letter 纸的标签为 2.63 × 1 英寸；打印结果相同）：

| 纸张 | 尺寸 | 每张标签 |
|---|---|---|
| A4 纸，24 格 | 70 × 37 mm，3 × 8 | 二维码、短 ID、名称与位置 |
| A4 纸，65 格 | 38 × 21 mm，5 × 13 | 二维码与短 ID |
| Letter 纸，30 格（Avery 5160 布局） | 67 × 25 mm，3 × 10 | 二维码、短 ID、名称与位置 |
| 标签打印机纸卷 | 50 × 30、40 × 30 与 62 × 29 mm | 二维码、短 ID、名称与位置 |
| 标签机胶带，9 与 12 mm（Brother TZe 等） | 长 40 与 50 mm | 大号短 ID 与名称。无二维码 |
| 标签机胶带，18 与 24 mm | 长 50 与 60 mm | 二维码、大号短 ID 与名称 |

纸卷与胶带每页打印一张标签，按标签尺寸：在打印对话框中选择你的标签打印机与该尺寸。对接受图片的标签机应用，**分享为图像**会为每张标签生成一个 PNG。窄胶带没有足够空间放可扫的二维码，因此改为大号承载短 ID：扫描器从文本读取它（[扫描没有二维码的代码](#scanning-a-code-with-no-qr-code)）。

之后，**已打印？**会询问你刚打印的那批并记录；此后那些物品与位置显示琥珀色胶带。**最近批次**显示每批内容、创建时间与地点以及是否已印；尚未确认的可在那里标为**已印好**或**未印**，并以相同代码重印。在纸张未确认时再次打印相同物品，会提供那张纸而不是新纸。ID 仍待定的物品尚不能打印。

## 扫描

首页与搜索上的**扫描**会打开摄像头。

| 你扫到 | Kept |
|---|---|
| 对应你可见物品的 Kept 标签 | 打开它并标记为刚刚见过 |
| 没有二维码的 Kept 代码（窄胶带） | 打开它（从文本读取），或读取不清时先问**这是该代码吗？**（[下文](#scanning-a-code-with-no-qr-code)） |
| 空白标签 | 提供**在此新建箱子**、**附加到现有物品**或**附加到现有位置**（房间、架子或点位） |
| 商品条码 | 提供将其添加为新物品；管理员开启条码查询时，名称来自 Open Food Facts、Open Products Facts 或 Open Beauty Facts |
| 某物品拥有的序列号或资产标签 | 打开该物品 |
| 某物品拥有的条码 | 打开该物品；多件时会询问是哪件 |
| 尚不属于任何物品的代码 | 说明其类型并提供添加为新物品，把代码保留为其条码或序列号 |
| [Homebox 导入](/zh/users/import-export/)后的 Homebox 标签 | 打开导入的物品 |
| 其他 | 说明它不是 Kept 标签 |

为位置认领的标签会以其显示为琥珀色胶带，与为它印刷的一样。认领可离线工作：在手机上等待同步，若另一部手机先认领了同一标签，会告诉你现在归谁。成员、管理员与所有者可认领；查看者不能。

要为已贴了空白标签的位置打标，打开该位置并选择**添加标签代码**（在管理下）：扫描器会打开，你扫到的空白标签会优先提供该位置。

标签贴在其所贴对象上。[隔间被合并](/zh/users/locations/#merging-and-splitting-compartments)时，被合并掉的隔间的标签会打开合并后的隔间；拆分则把标签还给各自。家具[转向](/zh/users/locations/#turning-furniture)时，每个隔间保留其标签，无论是否重新编号。

Kept 读取的代码，以及新物品把它们保存为何物：

| 代码 | 通常在 | Kept 保存为 |
|---|---|---|
| 二维码 | Kept 标签、Homebox 标签 | 标签 |
| EAN-13、EAN-8、UPC-A、UPC-E | 商品 | 条码 |
| Code 128、Codabar | 商店、资产与图书馆标签 | 条码 |
| ITF-14 | 纸箱 | 校验位正确时为条码；否则由你选择 |
| Code 39、Code 93 | 资产标签、IT 贴纸 | 序列号，或你选择时为条码 |
| Data Matrix | 电子设备、充电器、零件 | GS1 代码：其 GTIN 作条码、其序列号作序列号。纯文本：由你选择 |
| PDF417、Aztec | 运输标签、保修卡、门票 | 由你选择；任一字段放不下的文本（条码 64 字符、序列号 100 字符）不会保存 |

在上述任何情况中，Kept 标签优先。序列号按存储时精确匹配，且仅在线：手机的离线副本不保存序列号。带括号输入的 GS1 代码，如 `(01)04006381333931(21)K7Q2X9`，读取方式相同。

标签磨损，或没有摄像头：**输入代码**。拍摄摄像头也能识别 Kept 标签，并提供打开该箱子或向其拍摄。

### 扫描没有二维码的代码

没有二维码的标签（窄胶带）按其印刷短 ID 扫描。把**扫描**对准代码，使其约占摄像头宽度的三分之一，并静止片刻：Kept 会从文本读出六个字符并打开物品（如同二维码），消息会说明读到了哪个代码。

- **在手机上，离线也可。** 读取发生在手机上；画面绝不发送到任何地方。对手机副本中的任何内容，无需连接也能工作。
- **绝不会打开错误物品。** Kept 仅在每个字符都清晰、连续两次读出，且代码属于你时才打开。不确定时，它会显示读到的代码与将打开的对象，并在打开前问**这是该代码吗？**与你任何标签都不匹配的代码不会打开任何东西：**重新扫描**，或**输入代码**。
- **仅 Kept 自身印刷。** 它按 Kept 印刷的样式（其自有字体）读取短 ID。手工输入到标签机、用标签机字体的代码可能读不出：改为输入。

只有**扫描**读取印刷代码。扫描会话、箱子核对与拍摄摄像头只读取二维码与条码。
