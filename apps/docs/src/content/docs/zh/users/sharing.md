通过邀请人员来分享位置，每人带一个角色和可选的结束日期。你的个人位置从不分享：它没有成员、邀请或分享链接。

本页涵盖邀请、角色、分享链接与打印。

## 邀请人员

创建位置后，首页会出现**邀请人员加入 …**卡片。同一页也在**位置设置 → 成员 → 邀请**下。

1. 选择**角色**，在**访问**下选**无结束日期**或**至某个日期**。他们的访问会在该日期停止，他们为 API 创建的令牌也随之失效。
2. **创建邀请链接。** 链接只能使用一次，有效期 7 天。出示二维码供对方用手机扫描，或复制链接。待使用的邀请会显示在**成员**下，直到被使用；你也可以在那里撤销它。
3. **通过邮件发送**仅在服务器已配置邮件时可用。

没有邮箱地址的人也可以获得账户：所有者与管理员从**位置设置 → 成员 → 添加无邮箱人员**添加。这会成为受管账户——Kept 为其生成一个无法收信的地址，用重置码设置密码，所有者会收到每个新账户的通知。

除所有者外，任何人都可以**离开此位置**。实例管理员除非被邀请，否则看不到某个家内部的情况。

## 角色

| 角色 | 在该位置能做什么 |
|---|---|
| **所有者** | 一切，包括两步验证规则、转让与删除。只有一位所有者。 |
| **管理员** | 邀请与移除成员和查看者、更改设置与模块、导入导出、创建分享链接与理赔文件包、永久删除。只有所有者能授予或撤销管理员。 |
| **成员** | 添加、编辑、移动、借出与移入回收站物品；记录读数与保养；打印标签；使用 AI 拍摄。金额可见。 |
| **查看者** | 仅查看与搜索。除非位置允许查看者看到金额，否则金额隐藏。助手会回答，但不能更改任何内容。 |

## 分享链接

分享链接让没有账户的人只读查看箱子、位置或搜索的内容。所有者与管理员可从以下入口创建：

- 箱子的**操作 → 分享只读链接**。
- 位置的**管理**部分。
- 搜索上的**分享此列表**：筛选到某一位置的搜索，不含状态或价格筛选。

选择有效期：一天、一周、30 天（默认）、90 天或一年。链接只显示一次，因此请立即复制。

### 他们看到什么

每件物品的名称、照片、类型、所在位置、数量、状况与备注，按 A 到 Z 排序。从不显示价格、序列号、机密字段、人员、借出或文档。回收站中的物品、草稿，以及你已售出或丢失的物品不会显示。

### 保持最新

页面在打开时显示箱子、位置或搜索的当前状态。搜索的链接与其关键词以及场所、类型、标签筛选一致。

### 管理链接

**位置设置 → 分享链接**列出每个链接及其状态与打开次数。

- **以接收者身份预览**按接收者所见显示页面。
- **撤销**立即结束链接。
- 链接也会在过期时、或创建者不再管理该位置时停止。

## 打印清单

要把纸质清单交给别人，就打印它。位置上的**打印库存清单**会生成按场所分组的物品 PDF，含照片与短 ID。价格仅对能看到金额的人显示。任何能查看该位置的人都可以生成。

**邮件发送给我**也会在就绪时把 PDF 发到邮箱，**重新发送**会在每周一或每月 1 日把整个位置发到邮箱。设置 → 我 → 通知会列出并可停止这些发送。超过 10 MB 的报告不会作为附件发送：改为直接从 Kept 打印。
