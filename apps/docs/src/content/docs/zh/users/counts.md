盘点会保留每次结果。**盘点**列出某位置的每次盘点与箱检，最新的在前；盘点页会显示找到了什么、仍缺什么，以及每件物品现在在哪里。

可从 **更多 → 盘点**、位置页面（**盘点**）或位置页面（**历史盘点**）打开。保存盘点后，**查看本次盘点**会打开它。

## 盘点列表

可按盘点内容搜索，并按类型（盘点、箱检）、位置、盘点人、**有缺失**和日期筛选。可按位置、人员或月份分组。列表分页，且每个筛选条件都在地址栏中，因此筛选后的列表可以书签保存或存为视图。

## 盘点页

- **在 Y 中找到 X**、何时、耗时多久、谁盘的（共享盘点中是所有人），以及谁完成的。
- **与同一位置或箱子的上次盘点相比**：“1 件新缺失，0 件找回，2 件新物品”，并有链接指向上一次。
- 其中的各个列表，每行链接到物品及其当前位置：

| 列表 | 含义 |
|---|---|
| 找到 | 盘点时读取到：标记为已见 |
| 缺失 | 在清单上，未读取，且未标记“不在此” |
| 在别处找到 | 在此读取到，但 Kept 记录在别处，而你把它留在了那里 |
| 已移到此处 | 在别处找到，然后移到这里 |
| 已标记不在此 | 在汇总页上选择 |
| 已借出、维修中、在回收站 | 从不缺失：因 Kept 已知的原因不在 |
| 未盘点：后层货架 | 在无人盘点的区域（见下文） |

盘点后被丢入回收站的物品仍会显示，并标记为**已丢弃**。

**导出 CSV** 将盘点保存为表格：物品、短 ID、预期位置、结果、在多少件中找到多少件，以及现在在哪里。

Kept 1.14 之前保存的盘点只显示总数；它们不记录缺失或在别处的情况。

## 有原因则从不“缺失”

已借出、维修中或在回收站的物品从不列为缺失。汇总会为每类单独分组，例如“与 Murdock 在一起 (3)”、“维修中 (1)”，盘点也保持这种方式。

## 未盘点，以及“我检查过了”

对含有子位置的位置（或整个位置）进行盘点会有**区域**：该位置及其内部每个位置。完全未读取到内容的区域是**未盘点**：其物品列在“未盘点：后层货架”下，而不是“缺失”下。如果你查看过且这些物品确实不在，点**我检查过了**：它们会变为“缺失”。

## 按数量盘点

有数量的物品（6 罐）在读取到其标签时计为全部。用其行上的 **−** 和 **+** 说明找到了多少。不足时，选择**将其余标记为不在此**：其余会拆成单独一行并标记“不在此”，与箱检相同。撤销会将其合并回去。

## 一起盘点

在线开始的盘点是共享的。其他打开同一位置盘点的人会看到 **Sam 正在盘点：加入**。加入后，你读取的内容会记入同一次盘点，每次读取都记录读取者；汇总会显示其他人找到的内容，其区域也计为已盘。在那里盘点的任何人都可以完成，完成需要网络连接。跨多天加入的盘点会保持打开，直到有人完成。

## 标签覆盖

盘点设置会说明该处有多少物品有标签（“此处 62% 的物品有标签”），并提供**为其余打印标签**。没有标签的物品从不缺失：如果看到了就在汇总上勾选。

## 计划盘点

在位置页面上，**定期盘点**可计划每 1 到 24 个月盘点一次。它是该位置的日程，具有通常的提醒（提前一周）、到期与逾期，以及“需要你处理”磁贴。盘点该位置（无论是否包含内部位置）会将其标记为完成；撤销盘点也会撤销该标记。要定期盘点整个位置，请在其顶级位置上计划。
