**位置**说明物品在哪里。**标签**说明它还是什么：*露营*、*冬季*、*孩子*、*易碎*。一件物品最多 50 个标签；一个账户最多 1,000 个。

标签属于账户，因此该账户的每个位置共享它们。只有物品有标签（箱子也是物品）；位置、文档与人员没有。

## 添加标签

- **物品页面：****标签 → 添加标签**。选一个，或输入新名称并**创建**。与现有标签相近的名称会列在**你是否想查找**下方，这样 *Campng* 不会变成第二个 *Camping*。
- **添加物品时：****添加物品**中的**标签**字段。
- **拍摄：**名称下的**添加标签**。标签会保留给下一次拍摄，与位置一样。
- **一次多个：**在位置的内容列表、标签页或收件箱中**选择**，然后**添加标签…**或**移除标签…**。其他标签保持不变。
- **表格视图：****标签**列，以及选中后的**标签…**。

每次更改都有**撤销**。

|---|---|---|---|---|
| 查看标签、按其筛选 | ✓ | ✓ | ✓ | ✓ |
| 为物品打标签、新建标签 | ✓ | ✓ | ✓ | |
| 重命名、改色、合并、删除标签 | ✓ | ✓ | | |

## 颜色

每个标签的颜色取自固定的十二色集合，均考虑了明暗主题下的可读性。新标签使用最少被采用的颜色。在**设置 → 账户 → 标签 → 编辑**中更改。来自 Homebox 导入的颜色会取十二色中最接近的一个。

## 标签页

在物品页面上点按某个标签，或在**设置 → 账户 → 标签**中点按某一行。它会跨你的所有位置列出带有该标签的全部内容，并显示各位置的数量，以及列表常规的搜索、筛选与分组。所有者与管理员可在此重命名、改色、合并与删除。

- **合并**把一个标签并入另一个：其物品会获得另一个标签。
- **删除**仅适用于没有任何物品（含回收站中的物品）持有的标签。否则请改用合并。
- 重命名、改色、合并与删除可在 7 天内撤销。

## 按标签查找

- **筛选 → 标签：****是任一**、**具有全部**（带有每个所选标签的物品）或**不是任何一个**。
- **显示 → 分组：标签**把每件物品列在其第一个标签下，按 A 到 Z；无标签的物品排在最后。
- 搜索能找到标签名称，按含义搜索也认识它们。

## 离线

手机会保留你的标签：标签块会显示，标签筛选在离线搜索中可用。你添加或移除的标签，以及新建的标签，会保存在手机上并在恢复联网后同步。

## AI 与 MCP

- **拍摄：**AI 开启时，照片会从你自己的列表中推荐标签，绝不发明新标签。在收件箱中确认或拒绝。
- **MCP 与助手：**`get_thing` 返回标签；`list_tags` 列出标签；`tag_things` 添加或移除；`search_things` 接受多个标签（任一或全部）；`add_thing` 与 `update_thing` 接受标签名称。

## 导入

- **Homebox：**标签连同颜色一并带入；嵌套标签会被摊平。Homebox 位置上的标签不会保留，导入报告会说明。
- **CSV：**`tags` 列会创建其列出的标签。
