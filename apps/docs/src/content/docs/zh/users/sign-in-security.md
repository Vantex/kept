**设置 → 登录与安全**保存你账户在密码之外的登录方式：通行密钥，以及验证器应用的两步验证。

## 确认是你

本页上的每次更改都会先询问：

- 有密码的账户：**你的密码**；
- 没有密码的账户（仅通行密钥、邮件链接或 Google）：**最近十分钟内的一次登录**。超过十分钟，表单会提供**重新登录**。

在有密码的账户上添加通行密钥也会询问密码，并且无论何种账户都始终需要最近十分钟内的一次登录：此时由浏览器运行其自身的通行密钥对话框。开启或关闭两步验证不算重新登录。

**登录方式**中解除 Google 或你的 OIDC 登录，询问方式相同。

除重命名通行密钥外，每次更改都会登出所有其他设备。添加或移除通行密钥、解除外部登录、开启/重新设置/关闭两步验证、生成新的备用码时，Kept 会发邮件给你。每次备用码用于登录时也会发邮件，含时间、设备、剩余码数，以及若不是你时该怎么办。受管账户（用户名、无邮箱）不会收到邮件。

## 通行密钥

通行密钥用 Face ID、指纹或手机屏幕锁登录，无需输入密码。Kept 从不见到它：它留在设备上或你的密码管理器中。它绑定一个地址：在有[多个地址](/zh/install/home-network/#more-than-one-address)的 Kept 上，请在主地址处添加与使用。

| | |
|---|---|
| **添加通行密钥** | 为其命名（Kept 会建议设备名：“Mac”、“iPhone”），然后回应浏览器对话框。关闭该对话框不会更改任何事。 |
| **已同步** | 你的密码管理器或平台也会把它保留在你的其他设备上。 |
| **仅此设备** | 它只存在于这台设备或安全密钥上。 |
| **重命名** | 名称由你定，最多 64 字符。 |
| **移除** | 它停止为你登录。若不再想留在设备上，也请在设备上删除它。 |

Kept 添加的每个通行密钥都会验证是你（Face ID、指纹或 PIN），因此仅凭通行密钥登录本身就构成两步验证，包括在要求它的位置中。

## 验证器应用

使用 1Password、Google Authenticator 或 Aegis 等应用的两步验证：在密码、邮件链接或 Google 之后，登录会要求其 6 位验证码。

- **开启：**确认是你，扫描二维码（或输入密钥），输入一个验证码，然后保存十个备用码。仅当该验证码匹配时才算开启。
- **还剩 8 / 10 个备用码：**每个备用码可登录一次，供手机丢失时使用。
- **新的备用码：**十个新码，只显示一次。旧码失效。
- **重新设置：**换新手机或换应用时。扫描新二维码并输入新应用的验证码。在此之前，当前应用仍可用；中途关闭表单则无任何更改。完成后，旧应用的验证码与旧备用码失效。
- **关闭：**登录不再要求验证码。

## Kept 拒绝什么

无论界面如何显示，以下由服务器拒绝：

- **移除最后一种登录方式。** 当没有其他方式能为你登录时——密码、另一个通行密钥、Google 或 OIDC 登录（该 Kept 仍提供时）、或邮件链接（该 Kept 能发信且你的地址已验证）——不能移除通行密钥，也不能解除 Google 或 OIDC 登录。
- **在要求两步验证的位置关闭两步验证。** 只要你所属的位置要求两步验证且你没有通行密钥，验证器应用就保持开启。请先添加通行密钥。同样，当此类位置依赖你的最后一个通行密钥且应用已关闭时，最后一个通行密钥不能移除。
- **在该 Kept 能发信时、地址尚未验证就添加通行密钥或应用。** 先用发到该地址的链接登录一次，然后重试。

## 应用锁不是通行密钥

**设置 → 此设备 → 用 Face ID 或指纹解锁**只在已登录后解锁该一台设备上的 Kept（[应用锁](/zh/users/phone-app/#the-app-lock)）。它不能为你登录。若浏览器在登录时提供它、而 Kept 回答*该通行密钥不是此账户用于登录的通行密钥*，请换一种方式登录，再在这里添加真正的通行密钥。
