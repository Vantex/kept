没有 AI Kept 也能工作。连接提供商会增加三件事：根据照片以及收据、标签和仪表读数命名物品；能回答你关于库存问题的助手；以及借助嵌入模型的语义搜索。密钥由你自备；Kept 没有自己的 AI 服务。

## 提供商

| 提供商 | 照片与收据 | 助手 | 语义搜索 |
|---|---|---|---|
| **Groq**（推荐） | 是 | 是 | 无嵌入模型 |
| **OpenAI** | 是 | 是 | 是 |
| **Anthropic** | 是 | 是 | 无嵌入模型 |
| **Google**（Gemini） | 是 | 是 | 是 |
| **OpenRouter** | 是 | 是 | 是（其嵌入模型） |
| **OpenAI 兼容**（Ollama、LM Studio 等） | 你指定的模型 | 你指定的模型 | 若服务器提供 |

**Groq 配合 `qwen/qwen3.8-27b`** 是推荐组合：Kept 测得最便宜的可靠结果，每张收据约 0.004 美元（合成测试图像，2026-09-26）。粘贴 Groq 密钥即会选中它，页面上的 **Why?** 会给出数字。Kept 为每个提供商和任务建议模型；可在 **Advanced** 下从提供商列表中任选，或输入任意模型 ID。

## 密钥放在哪里

密钥有三处，且没有按位置的密钥：

| 密钥 | 设置位置 | 为谁付费 |
|---|---|---|
| **账户的密钥** | **Settings → AI**，由账户所有者设置 | 该账户拥有的每个位置 |
| **你的个人密钥** | **Settings → AI → Personal AI key** | 你的 Personal 位置、你的私密助手会话，以及跨所有者的问题。配合 [Personal 隐藏](/zh/users/locations/#hide-personal)，当该位置所属账户没有密钥时，也覆盖你独自拥有并使用的位置 |
| **本服务器的密钥** | **Admin → AI**，由实例管理员设置 | 任何没有自己密钥的账户 |

在某个位置中的工作（为照片命名、关于它的助手回答）由**该位置的所有者**付费，因此 Alfred 的“Family house”成员用的是 Alfred 的密钥，而不是自己的。成员和查看者会看到一条只读说明，写明谁付费。

**连接：** 在 **Paste your key** 中粘贴密钥。Kept 尽可能从密钥识别提供商（否则在 **Advanced** 中选择），然后 **Save and test** 会检查模型能否读取照片并给出结构化回答，并说明测试花费。密钥是只写的：Kept 永不显示已保存的密钥，**Replace key** 可更换。服务器上第一个密钥之前，实例管理员必须保存[恢复套件](/zh/admin/recovery-kit/)：密钥是 Kept 必须能从备份中恢复的秘密。

**Advanced** 中有提供商与 base URL、每个任务的模型（**Models**）、**Reasoning effort**（默认 low），以及上限与价格。

**Models：** 列表来自提供商本身，选择器每次打开时请求（Kept 会复用十分钟；**Refresh list** 再次请求）。OpenRouter 的 `:free` 模型也在其中，标记为 “free: shared, may be busy”：共享池经常返回 “busy”。每个选择器下，**Custom model id** 对所有提供商都可接受任意 ID，包括列表未显示的；**Save and test** 随后会检查。当提供商不返回列表时，输入 ID 是唯一办法。

## 什么会用 AI，以及花费多少

AI 设置打开时会显示 **What uses AI in Kept**：每个动作一行（拍摄的照片、收据、标签、读数、助手问题、搜索、测试），含调用次数、消耗的 token，以及按价格表计算的花费（有使用记录后取最近 30 天）。在 **This month** 下，每个上限一条柱显示目前花费。

- **拍摄**（物品、收据、标签、读数模式）：每张照片一次调用。名称、品牌、型号和类型会被填好；价格、日期、序列号和读数作为建议值留在收件箱中供你接受。每条 AI 填写的草稿都带一行，如 “Read by qwen/qwen3.8-27b (Groq), 2,502 tokens”，以及花费与付费方。
- **一张照片中的多件物品**（物品模式；Admin → Settings，默认关闭）：同一次调用最多为照片中 12 件物品命名。第一件填入拍摄自身的草稿并保留照片；其余每件成为旁边的草稿，同位置同批次，各自从照片中裁出自己的图，在收件箱中确认、合并或丢弃。裁图质量取决于提供商的框，开启后请检查若干草稿。
- **房间照片**（房间模式）：每张照片一次调用，列出最多 60 个物体；多张照片时另有一次纯文本调用合并结果。物体成为房间中的草稿，各自带自己的图（[房间照片](/zh/users/room-photos/)）。
- **平面图**（位置地图的 **Start from a floor plan**）：每张图一次调用，读取其房间、标签与标注尺寸；Kept 推算尺寸与自身位置，由你在添加任何内容前核对（[位置地图](/zh/users/location-map/#start-from-a-floor-plan)）。面板会显示发送前一次读取最多可用多少 token：Groq 上约 11,000 token，是估算。
- **助手**在你的角色范围内根据库存回答，其使用的每个工具都会增加一次调用。它提出的更改以确认卡片显示，由你批准；对查看者是只读的。
- **导入后的搜索词**：导入时可能提供 **Add search words with AI?**，先显示 token 估算（[导入](/zh/users/import-export/)）。

**AI usage** 页面列出每次调用：所有人有 **My AI usage**，位置的用量给其管理员与所有者，账户的给其所有者，实例的在 Admin → AI 下。各自显示总计、按天按任务堆叠的 token、按任务/人员/位置的分解（适用时），以及带 **Export CSV** 的调用列表。调用记录模型、token、结果与花费，从不记录提示词、照片、回答或密钥。

价格来自**价格表**，由实例管理员在 Admin → AI 编辑（对公布价格的提供商可用 **Fill from … listing**）。推荐的 Groq 模型价格已为你填好。没有价格的调用按 token 计入并显示为成本未知。

## 上限与暂停

除非有人选择，否则没有任何金额限制：第一个密钥之后 Kept 会提供 **Set a monthly limit?** 及建议金额，以及 **No limit**。在 **Advanced** 下，**Limits** 包含：

- **每月金额**（服务器已启用的货币）与**每月 token**，针对账户；账户之内的位置自己的上限，由所有者设置；以及按人的上限。
- 照片与收据读取的 token 预算为每个付费账户每分钟 60,000、每天 2,000,000、每月 20,000,000，除非更改。
- **Pause AI** 手动停止所有调用，直到你恢复。

达到上限时，AI 只在该范围内暂停，并显示横幅，如 “AI paused until 1 Oct, Home's monthly cap reached”。**拍摄仍会保存；命名会等待**，AI 恢复时一并恢复。设置上限的人会看到 **Resume now**，可提高、移除或保持暂停。提供商自身的速率限制不是暂停：进度行会说 “Waiting for Groq, about 20 s” 并继续。

**一次助手请求会被控制在提供商每分钟限制内**，前提是提供商已对其命名（Groq 免费层：每分钟 8,000 token）。每个请求携带问题所涉及的工具：查找物品与日常更改始终包含，借用、日程、保修、文档、车辆、库存、历史或地点在问题（或会话最近几条）提到时包含，可用 Kept 的任何语言；模型请求但未发送的工具会在下一步发送。开启全部模块的首次提问在回答的配额之前约 3,100 token。若请求仍太大，Kept 会少发工具，然后要求更短的回答，再从发送内容中省略最旧的工具结果；会话仍保留它们。仍放不下的问题会以 “too large” 失败：用更高限制的模型或套餐来回答。

## 发送给提供商什么

Kept 自己的摘要，显示在每个提供商旁：

> 只有去除位置与相机数据后的照片副本，绝不是原件。固定指令与你位置的语言。对助手而言，是你的问题及其在你角色内查阅的库存。绝不发送机密字段。

平面图发送同类副本（PDF 首页绘制为图片，含该页文字），不发送你的位置、房间或楼层名称；平面图自身文字作为数据发送，Kept 从回答中保留的内容除其房间标签与尺寸外，不是名称、地址或数字。

其下，Kept 摘要提供商声明对 API 数据的处理方式（训练、保留），并链接其政策。你自己运行的服务器只保留你允许它保留的内容。

## 搜索与嵌入

关键词搜索始终可用，包括 AI 为物品添加的搜索词（按位置的各种语言）。语义搜索需要嵌入模型，来自三处之一，由服务器管理员用 `KEPT_EMBEDDINGS` 设置（[配置](/zh/reference/configuration/)）：

- `provider`（默认）：位置的提供商，当其有嵌入模型时（OpenAI、Google、OpenRouter，或 OpenAI 兼容服务器）。在 **Advanced → Models → Search** 下选择；OpenRouter 无默认并列出免费模型。Groq 与 Anthropic 没有，因此用它们时搜索仅限关键词并会说明。链上更上方的密钥若带 Search 模型（本服务器的）可覆盖自身没有的位置。

  当密钥有助手模型但无 Search 模型，且更上方也没有时，**Settings → AI** 会显示 **Search matches names only**，并给出步骤：**Choose a Search model**，或对 Groq 与 Anthropic 用 **Choose another provider**。Admin → Status → Search embeddings 统计仅按名称搜索的位置，但不点名。

  Kept 向 OpenAI 与 Google 请求 768 维向量。其他模型按自身长度回答，必须 ≤ 2,000：向量更长的模型不能用于搜索。返回向量长度与请求不同、或出现两种长度的请求会被拒绝且不存储。
- `local`：Kept 内置的小模型，无密钥、无按次花费。除非本地模型运行时已安装，否则 Kept 拒绝此设置。
- `off`：仅关键词搜索。

## 用 Ollama 跑本地模型

要把一切都留在自己的硬件上，用 Ollama 跑模型，并作为 **OpenAI 兼容**提供商添加其 base URL；此类 Kept 不预填任何内容，由你命名模型。私网地址需先由实例管理员在 Admin → Settings 中允许。设置、内存与 Compose profile：[Ollama](/zh/admin/ollama/)。

## 关闭 AI

- **对单个位置：** **位置设置 → 要跟踪的内容**，在 **AI in this location** 下关闭 **AI capture and the assistant**。拍摄仍可用；物品在收件箱中等待命名。
- **暂时：** Advanced 下的 **Pause AI**。
- **完全不连接：** 任何层级都没有密钥时不会发送任何内容，清单中的 **Connect an AI provider** 步骤可忽略。

AI 页面没有删除已保存密钥的按钮；可替换、暂停，或按位置关闭 AI。

:::note[把 ChatGPT 或 Claude 作为客户端]
“Connect ChatGPT or Claude”（Complete 预设）是反向工作的：你的 AI 应用通过 MCP 读取并更新 Kept，使用其自己的模型与订阅，配合你在 **Settings → Connections** 创建的令牌。参见[连接 AI 应用](/zh/users/mcp-clients/)，详情见 [MCP](/zh/developers/mcp/)。
:::
