Kept 在你的 Kept 地址后加上 `/mcp` 运行一个 [MCP](https://modelcontextprotocol.io/) 服务器，例如 `https://kept.example.org/mcp`。会说 MCP 的 AI 应用随后可以从你的库存回答“电钻在哪里？”，并在你允许时添加、移动与更改物品。

![Claude Code 连接到 Kept：“把我的电视加入客厅：Samsung QE55Q80C，序列号 0B7H3CJT500123”，以及 Claude 回复电视在 Kept 的 Home › 客厅下](../../../../assets/screens/claude-mcp-light.webp)

本页讨论 Kept 之外的应用。Kept 自带的助手使用相同工具，见 [AI 提供商](/zh/users/ai-providers/)。服务器内部如何工作见 [MCP 服务器](/zh/developers/mcp/)。

有两种连接应用的方式：

- **个人令牌：**任何允许你设置服务器地址与 `Authorization` 头的 MCP 客户端。
- **连接器（OAuth）：**应用把你送到 Kept 登录并选择它可做什么。这需要 Kept 位于应用可达的 `https` 地址上。

:::note[尚未对照各应用核验]
Kept 的测试以两种方式连接 MCP 客户端。对 claude.ai、ChatGPT 与 Claude Desktop 本身的核验仍待完成，因此尚不能确认哪些会以连接器方式连接。
:::

## 开始前

- **在应用应访问的每个位置开启“连接 ChatGPT 或 Claude”。** 它在**位置设置 → 跟踪内容**下，仅在**完整**预设中默认开启。所有者与管理员可更改。在关闭它的位置，令牌或连接器什么也够不到。
- **应用仅通过 `https` 创建令牌。** 设置 → 连接在 `KEPT_PUBLIC_URL` 为普通 `http` 时拒绝创建令牌。没有关闭此行为的设置。参见 [HTTPS](/zh/install/https/)。在 `http` 的家庭网络上，运行服务器的人可以改在那里创建：[`kept admin token create`](/zh/admin/cli/#a-token-from-the-server)。

## 创建个人令牌

打开**设置 → 连接**并选择**新建令牌**。

| 字段 | 填什么 |
|---|---|
| **名称** | 你将在何处使用它：“Claude Desktop，我的笔记本”。 |
| **位置** | 已为你勾选一个。仅当应用需要两个时再添加。 |
| **它能做什么** | **只读：**查找物品并读取已记录的内容。**读取与更改：**还可添加、移动或更改。两者都不能删除或查看机密字段。 |
| **过期时间** | 一个日期，或留空以保留到你撤销为止。它在当天结束时失效。 |

然后**创建令牌**。令牌绝不会做得比你更多：你是查看者的地方，它只能读。能在成员不同的多个位置更改物品的令牌会得到警告 **这些位置由不同的人使用**，因为应用可能借此把物品从一个位置移到另一个。**为它们全部创建**会继续；每个位置一个令牌是更安全的选择。

令牌（`kpt_` 加两段）只出现一次，带**复制**。Kept 只保存其指纹，因此丢失的令牌无法再次显示：撤销并另做一个。

在要求两步验证的位置，令牌仅当你在已用第二因素登录时创建才有效。

## 用令牌连接客户端

在新令牌下，**连接应用**显示两个值，各带复制按钮：

```text
Server address   https://kept.example.org/mcp
Authorization    Bearer kpt_…
```

在应用中，用该地址添加 MCP 服务器（也可能叫连接器或集成），并在该头中发送令牌。Kept 不为任何特定应用提供设置文件；地址与头填在哪里见应用自身文档。

该端点只响应 `POST`，请求之间不保留会话，并拒绝 `Host` 不是 Kept 地址（或其用过的地址）、或来自其他网站页面的请求。

## 以连接器方式连接（OAuth）

支持它的应用可以在不复制令牌的情况下连接。当 `KEPT_PUBLIC_URL` 为 `https` 时会自动开启。**管理 → 状态 → 来自其他应用的连接**显示 MCP 端点以及 **可用** 或 **需要 https 公开 URL**。

1. 在应用中，把 `https://kept.example.org/mcp` 添加为连接器。
2. 应用从地址找到 Kept 的登录页并把你送去 Kept。登录。
3. Kept 显示 **_应用_ 想要使用你的 Kept**。名称是应用自称的；Kept 无法确认是谁做的。选择**它能做什么**与**在何处**（只选它需要的位置），然后**允许**或**拒绝**。页面还会说明应用在你退出此浏览器后仍保持登录，以及任何会登出你所有其他设备的操作都会让它重新登录。
4. 该应用出现在**设置 → 连接**的**已连接应用**下。

该应用保持连接，直到你对其按**撤销**并确认（Kept 会问 **断开 _应用_？**），或直到它 30 天未被使用；之后必须重新登录。它获得的每个访问令牌有效期一小时，应用无需再问即可续期；Kept 在每次调用时检查你的授权，因此**设置 → 连接**中的**撤销**立即生效。

任何会登出你其他设备的操作之后，应用都必须重新登录：**登出所有其他设备**、新密码或密码重置、两步验证/备用码/通行密钥的更改、解除外部登录、新邮箱地址，或管理员在各处登出你或停用你的账户。登出单台指定设备不会让应用登出。

一个例外：请求删除账户会登出你的其他设备，但保留应用的登录。账户等待期间应用停止工作；若你保留账户，它无需重新登录即可再次工作。

会让连接器停止的情况：

- **应用够不到 Kept。** claude.ai 等网页应用从其自身服务器连接，因此 Kept 必须能从互联网访问，而不只是你的家庭网络或 tailnet。
- **Kept 够不到应用。** 应用用一个描述自身的 `https` 地址表明身份，Kept 会抓取该文档。私有与本地地址会被拒绝。
- **应用自行注册。** Kept 接受用此类文档（Client ID Metadata Documents）自我描述的应用，并已关闭动态客户端注册。只能动态注册的应用无法作为连接器连接；若它接受个人令牌，请改用令牌。

## 应用能与不能做什么

- **它只看到你选择的位置**，并且在每个位置只看到该位置开启了 Kept 部分对应的工具。你的角色会隐藏的值，对应用同样隐藏。
- **更改立即生效**，并在连接页的**来自连接的最近更改**下列出，带 **7 天内撤销**。若字段此后已变更，撤销会被拒绝。
- **没有可调用的破坏性操作。** 没有工具会删除、移入回收站、合并、转移所有权、揭示机密字段、上传文件或自行运行查询。
- **文件经由你。** `attach_link` 给应用一个打开 Kept 捕获表的链接；你在已登录状态下于那里添加照片或收据。
- **每个令牌的限额：**每分钟 120 次读取与 30 次更改。回答简短且分页，默认 20 项，应用可请求更多，最多 200。
- **人员写的文本标为不受信任。** 名称与备注以 `untrusted` 键到达应用，Kept 会告诉它绝不遵循其中的指令。

**物品的字段。** `add_thing` 与 `update_thing` 接受你在应用中可为物品设置的每个字段，各自独立字段而非备注：名称、数量、类型（按名称，英文或阿拉伯文，或按 id）、品牌（新建则创建）、型号、序列号、条码、颜色、状况、备注、其他名称、标签（新名称创建标签，成员及以上）、属于谁（一个人，新建则创建）、说明书链接、过期时间与提前多少天提醒、消耗品的最低量，以及按键设置的类型自有字段。`add_thing` 还接受其去向与购买（日期、单价含币种，以及商店）；`update_thing` 还接受其来源，以及其购买：日期、商店、其在收据上的明细行、单价含币种与备注，按物品页面的方式更改已有购买或记录一笔。机架中的设备接受 `rack_units`（其高度，导轨旁为 0）与 `rack_at`（从底部算起的最低单元、其面与是否全深），当应用拒绝已占用单元时同样拒绝。价格需要金额开启且角色能看到金额，与应用中一致；最低量需要**你已用完的物品**。Kept 不认识的类型会被略去，回答的 `not_set` 会说明；助手的卡片会显示为“未设置”并带选择器。

搬家工具仅供已连接的应用使用；Kept 中的助手不使用它们。

每个接受 id 的工具也接受 6 位短 ID，如 `K7D2QX`。完整契约在
[`packages/mcp/src/tools.ts`](https://github.com/keptinventory/kept/blob/main/packages/mcp/src/tools.ts)。

## 撤销访问

在**设置 → 连接**中，找到令牌或应用（按**类型**、**位置**或**状态**筛选）并选择**撤销**。

- **令牌：**使用它的应用立即停止工作。它做过的更改保留，仍可在 7 天内撤销。
- **已连接应用：**它立即停止访问你的 Kept，Kept 会忘记你的同意，因此要再用需从应用重新连接。

Kept 也会自行结束访问，列表会说明原因：**已过期**、**已结束：你离开了该位置**、**已结束：你的角色已变更**、**已被管理员撤销**，或**已被应用断开**。
