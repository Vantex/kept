在电脑上（窗口宽 1024 像素及以上），位置的**表格**把其中每件物品显示为一行，便于一次整理大量物品。手机仍使用列表。

![位置显示为表格：名称、所在位置、短 ID、类型、品牌与型号列；选中两行后上方出现移到、标签、设置字段与移到回收站；已更改的型号单元格高亮，底部为“保存 1 处更改”](../../../../assets/screens/sheet-desktop-light.webp)

![深色主题下的同一表格](../../../../assets/screens/sheet-desktop-dark.webp)

- **列：**名称、所在位置、短 ID、类型、品牌、型号、序列号、数量、标签、购买日期、价格、保修截止、状况、颜色、条码、属于、过期时间、备注、最近出现与已更改。**列**选择显示哪些；Kept 会在该电脑上记住你的选择。价格仅在你能看到金额时显示。
- **搜索、筛选、视图、排序与分组**与位置列表一致，并保存在地址中。点列头按该列排序；再点一次反转顺序。
- **就地编辑：**双击单元格、按 **Enter** 或 **F2**，或直接开始输入。名称、所在位置、类型、品牌、型号、序列号、数量、标签、状况、颜色、条码、属于、过期时间与备注均可编辑；价格、购买与保修在物品页面编辑。更改过的单元格变为琥珀色，在**保存 N 处更改**之前不会保存。适用与物品表单相同的校验（名称必填；有序列号的物品数量保持为 1）。
- **选择行：**用每行开头的方框、**空格**、**Shift+↑/↓**、**Shift-点按**选范围，或 **⌘/Ctrl-点按**再加一行。然后可**移到…**（本位置的房间、点位或箱子）、**标签…**（添加或移除）、**设置字段…**、**拿起**、**打印标签**、**加入事件**与**理赔文件包**，或**移到回收站**。移动、标签与字段与其他更改一样等待**保存**；回收站立即执行，一次最多 200 件，会先询问箱内物品的去向以及任何借出中的物品。列表与网格共用此工具栏（[位置、房间与箱子](/zh/users/locations/)）。
- **撤销：**保存后，一次**撤销**会收回其中全部更改。**移到回收站**后，一次撤销会全部恢复。
- **他人改过某行：**在你打开表格之后，其他行仍会保存，那一行会保留你的更改并在行首给出警告。打开它可**保留我的**（用你的覆盖对方）或**保留对方的**。
- **导出**把各行下载为 CSV，与列表页相同。

按键：方向键在单元格间移动（Home 与 End 到行首行尾，Page Up 与 Page Down 每次十行），**Tab** 横向移动，**Enter** 编辑或保存单元格并下移，**Escape** 取消编辑或清除选择，**Delete** 清空单元格（名称、数量或位置除外），**⌘/Ctrl+A** 选中已加载的全部行，**⌘/Ctrl+S** 保存。查看者能看到表格但不能更改。
