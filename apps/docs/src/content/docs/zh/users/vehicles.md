Kept 跟踪任何带仪表的东西：汽车、发电机、锅炉、割草机。类型为带仪表的物品会有**表计**：读数、保养与计划任务。**车辆**（家居与完整预设）把所有车辆聚到一处，各有概览、读数、保养、文档、费用标签页，完整预设下还有燃油。

本页涵盖记录读数与保养、计划任务、燃油与历史报告。车辆能承载的地图形状参见[地图形状](/zh/users/map-shapes/)。

## 记录读数

读数可在首页、车辆页面与离线时记录。无法落在相邻读数之间的读数会被拒绝，Kept 会说明原因。仪表盘照片会加入车辆的凭证照片。

## 记录保养

保养记录承载这次到店的全部内容：

- **日期**与当时的**读数**。
- **商店**与**发票**。AI 可从发票填写明细行。
- 各**明细行**及其费用。
- **已完成的计划任务**：保存会重置其计数。
- **从库存**行（见下）。
- **备注**。

在车辆的**保养**标签页上，点按某次保养可打开它：其全部内容，含备注。

- **编辑**打开同一表单，已填好。保存只更改你改动的部分。
- **删除**会先询问，然后提供**撤销**。其明细行与发票一并删除；它完成过的计划任务从上一次保养重新计数。
- 谁可以：记录者，以及该位置的所有者与管理员。查看者可以打开，不能更改。
- 仍在读取中的发票是**草稿**：**完成记录**或**丢弃草稿**。

## 从库存取用

当该位置开启了消耗品时，保养明细行可从同一位置选择消耗品：架子上的机油滤清器。

- 保存会按该行的数量（数量为空时为 1）扣减消耗品计数。
- Kept 拒绝超过剩余量的扣减。
- 编辑该行、移除它、删除保养或撤销上述任一操作，都会把计数改回正确值。
- 仍在读取中的发票在你保存前不扣减任何东西。

消耗品的**历史**会显示使用记录，并链到对应保养。

助手与 MCP 客户端可以同样方式记录保养（“用了 4.5 升机油”）。助手的确认卡片会在任何库存变动前显示每条**从库存**行。

## 计划任务

计划任务是再次做某事的提醒，按日期或按读数。

- **添加入门计划**会加上常用项：换机油、换轮胎、刹车油、空气滤清器。
- **一次性**（一个日期、不重复）在你完成即结束。它离开到期与逾期列表，**计划任务**会以**已完成**及日期列出。撤销完成，或删除那次保养，它会再次到期。
- 到期与逾期的计划任务出现在首页的**需要你处理**，以及日历订阅源与通知中心。参见提醒与通知。

## 燃油（完整预设）

在完整预设上，**燃油**标签页记录每次加注。表单要求**数量**（按你的单位：升、加仑，或电动车的 kWh 充电）与**费用**；单价由这两项算出，无需输入。还有日期与时间、**油箱加满**或**部分**、里程表（可选，会与前后读数核对）、里程表照片、加油小票、备注，以及加油站——保存时新加油站会加入你的供应商。**在此之前我漏了一次加注**会标记一个空档，使油耗保持正确：油耗从一次加满量到下一次加满量之间计算，并在两次带里程读数的加满后再次显示。

## 单位

- **里程表：**新车辆的里程表以 **km** 计数，或当你的**单位**设置（设置 → 我 → 显示）为**英制**时以 **mi** 计数。发电机的表计以小时计数。
- **更改单位：**所有者与管理员可在概览的里程表卡片上找到，也可在物品页面的表计上找到。里程表在 km 与 mi 之间切换只有两种方式：
  - **仅改标签：**读数本来就是新单位下的。每个值保持原样。
  - **换算读数：**每个读数（含待审核的）、替换偏移、每日限额，以及按里程表运行的计划任务（每多少 km、其前提醒、从哪个读数起算，以及推迟到某读数）都按 1 mi = 1.609344 km 换算到千分位。

  保存前，Kept 会显示有多少读数会变更以及最新一条的前后值。更改会以**表计单位已更改**进入车辆历史，随后的消息提供**撤销**，可把每个值精确还原。此后表计上任何内容变更过（记录、保留或编辑过读数，或改过计划任务）都会拒绝撤销并说明原因。小时表或自定义表只能改标签。
- **读数与加油量**按输入保存。只有**换算读数**会更改读数，且可撤销。加油量（升、加仑、kWh）从不换算。
- **油耗**跟随你的**单位**设置，无论里程表用哪种单位计数：公制下为 **L/100 km**，充电为 **kWh/100 km**；英制下为 **mpg**（美制加仑）或 **mi/kWh**。小时表上则按小时，用你输入的单位。历史报告的 PDF 跟随生成者的设置。
- **另一单位下的仪表盘照片：**当照片显示英里而里程表按 km（或相反）时，读数会像所有照片读数一样在收件箱中等待。其卡片会说明照片显示了什么，并给出里程表单位下的值，附使用按钮。在你选择之前不会换算任何值。

## 费用

车辆的**费用**标签页显示其燃油、保养与规费。洞察在**车辆成本**下跨你的车辆显示相同数字。

## 读取登记卡

在标签模式下，**读取卡片**会读取登记卡：VIN、车牌与驾照有效期。

## 历史报告

**历史报告**生成某个时间段的 PDF：含凭证照片的里程表历史、带发票的保养、燃油与文档，以及仅在你能看到金额时的费用。
