**首页**是第一个屏幕：先看需要你处理的事项，再看物品在哪里。手机上按此顺序单列显示；电脑上，位置和最近动态在左侧，快捷方式和洞察在右侧。

- **开始使用**：一行显示你的进度和下一步。箭头展开步骤；**×** 永久隐藏（消息中有撤销；**帮助 → 入门清单** 可再次显示）。全部步骤完成后会自动消失。
- **需要你处理**：六个计数，位置固定不变：**已逾期**、**到期**、**即将到期**、**已借出**、**不确定**和**低库存**。为零的项会置灰，而不是隐藏。**已借入**和**长期未见**在有内容时才出现。电脑上每项还会显示最紧急的一条。点按可打开已筛选的列表。已借出在 Lending 模块开启时显示，低库存在 Consumables 模块开启时显示。
- **快捷方式**：**拍摄**、**扫描标签**、**记录读数**（当某物有仪表时）和**添加物品**。
- **位置**：每个位置一张卡片，含小幅地图示意、其物品数、位置数与价值（Money 开启且你能看到金额时），以及该处被标记的事项，例如“2 件物品需要位置”或“1 项逾期”。点按卡片打开该位置。
- **最近动态**：手机上最新 3 条，电脑上 5 条；**已添加**、**已移动**和**已检查**可缩小范围，**全部动态**打开完整列表。**待审核照片**显示收件箱中等待处理的内容。
- **洞察**（Money 开启时）：今年到目前为止你在物品上的花费（含往年），以及你所拥有物品的价值。每种货币单独一行，从不换算。会说明排除了哪些位置。

第一天使用时，首页会显示欢迎信息、**创建你的第一个家**及其后续步骤、你的 Personal 位置，以及已经可用的快捷方式。

有两个细节能让计数保持诚实：每个计数都等于它所打开列表的长度（点进去数字对得上），以及“今天”按各位置自己的日期——已过午夜的位置仍会把当地到期项计为到期。

每个计数、快捷方式和卡片打开什么，详见[日常使用](/zh/users/everyday-use/)；金额视图另有独立页面（洞察）。
