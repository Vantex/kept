借出一个装有十二件物品的箱子，其中一件没回来，或回来时坏了：每件物品都保留自己的记录——谁持有、何时、发生了什么。什么都不会丢。

## 借出箱子或套件

箱子上的**借出**与其他物品一样：借给谁、何时归还、借出时的状况、备注与照片。这是一次**交接**，有一行给箱子，以及给里面每一件物品（一直到最深层），每件都记住自己原来的位置（“在 Camera bag › Lens pouch 中”）。

- 里面已经借出、维修中或不再使用的物品仍留在原处；Kept 会说明。
- 套件还会列出**不在套件中的零件**（“备用电池在客厅”）：勾选也要一起借出的。
- 什么都不会移动：每件物品都显示 **Since 3 Oct 与 Sam 在一起（在 Camera bag 中）**。
- **撤销**可在 7 天内收回整次交接，前提是其中没有任何变化。

Kept 会在到期前两天以及逾期时提醒你。它从不给借用人发消息。

## 借出期间

每件物品不能再借给别人。移动它、丢弃它或往已借出的箱子里放新东西都会**先询问**（“这件与 Sam 在一起：先标记归还，还是继续？”）。没有你确认，什么都不会改。

## 归还

**标记全部归还**（在箱子上，或在人员页面上）会显示仍在外面的每件物品，每件都默认勾选**已归还**。对每件选择：

| 选择 | 结果 |
|---|---|
| 已归还 | 回到原处；补充归还时的状况 |
| 已损坏 | 同上，并加备注与**更新其状况** |
| 未归还 | 仍留在对方处；提醒继续 |
| 丢失 | 该行以丢失结束，物品标记为丢失，从不删除 |
| 归还了几件（数量） | 其余留在外面，作为单独一行 |

交接会显示“12 件中 11 件已归还”。**撤销**会把每一行恢复原样。未归还的物品稍后在其自己的页面上处理：**标记归还**，或**丢失**。

## 显示在哪里

- **物品的 Loans 标签页**：每次借用，含对方、带了什么、双方备注与状况，以及如何结束。
- **人员页面**：对方仍持有的东西，按交接分组（“与 Camera bag 在一起的 3 件物品”）。
- **箱子的 Loans 标签页**：其交接以及归还了几件。
- **历史**：“将 Camera bag 借给 Sam”、“从 Sam 处归还，已损坏”、“由 Sam 弄丢”。

## 套件

**套件**是带零件清单的容器：里面应该有什么。零件被移走、借出或丢失后，套件仍知道。

- 容器上的 **Parts → 将此设为套件**：其内容被勾选为零件；可通过搜索添加更多。一件物品最多是一个套件的零件，且在该套件所在位置。
- **Parts** 标签页会显示 **Complete**、“2 个零件不在套件中”或 **Since 3 Oct 与 Sam 在一起**，每个零件显示：在套件中、在别处（带**放回**）、缺失、与某人在一起，或在回收站。
- **检查此套件**会用[扫描会话](/zh/users/scanning-sessions/)盘点：其清单就是零件，无论它们在哪里。
- **编辑零件**和**不再是套件**可在 7 天内撤销。
- 搜索和列表可按 **Kits** 和 **Incomplete kits** 筛选。

## 权限

| | 所有者、管理员、成员 | 查看者 |
|---|---|---|
| 查看交接、行、套件零件 | ✓ | ✓ |
| 借出、归还、标记丢失 | ✓（需开启 Lending；关闭时仍可归还） | — |
| 创建套件、编辑零件、解散 | ✓ | — |
| 检查套件 | ✓ | 仅检查：不保存 |

借出与归还需要网络连接。离线时会显示状态（“与 Sam 在一起”），套件检查与普通盘点一样可用。Kept 导出会随位置带上交接、其行以及套件。
