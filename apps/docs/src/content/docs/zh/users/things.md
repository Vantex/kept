物品页面包含其照片、名称与 **ID**、完整路径，以及跟踪内容的各个分区：**详情**、**文件与保修**、**价值**、**表计**、**借出**、**理赔**、**链接**、**计划任务**与**历史**。在该位置关闭了对应模块的分区不会显示。

- **编辑**就地打开字段。若他人在你打开后改过同一字段，Kept 会显示两个值并询问：**保留我的**、**保留对方的**或**编辑**。只有一方改过的字段会直接合并，无需询问。
- **品牌：**从账户的品牌中选择，或输入新名称并选择**添加“…”**。任何能编辑物品的人都可以添加；所有者与管理员在**设置 → 账户 → 品牌**下重命名与合并。
- **类型：**Kept 内置类型与账户自有类型；在**编辑**中更改，或点按页面顶部的类型（没有类型时为**无类型**）。没有类型的物品只需选一个。从一种类型换到另一种时，Kept 会在保存前列出将被归档的值：它们会留在**已归档字段**下，切回时恢复。所有者与管理员在**设置 → 账户 → 类型**中用**自定义**更改内置类型，这会生成账户副本；此后副本才是各列表提供的类型，因此自定义过的类型只显示一次。
- **标签：**在电脑上，详情旁的**标签**卡片显示打印出来的标签样式（二维码、短 ID、名称），带**打印**与**下载**（PNG）。在手机上，详情中的**标签**行会打开它。参见[短 ID 与标签](/zh/users/short-ids/)。
- **购买：**何时何地购买、收据上的名称、单价、收据合计与税费，以及备注。成员及以上可用旁的**编辑**更改其中任何一项（也可在编辑物品本身时进行），或在没有购买记录时**添加购买**（金额模块开启处）。价格需要金额模块以及有权查看的人。一笔购买可以包含多件物品，如同一张收据：其日期与商店对所有物品相同，表单会说明这一点。**移除**会删除仅属于此物品的购买（连同收据），或把物品从共享的收据上摘下。保存在另一位置的购买（物品已移动）则在那里更改。
- **购买的收据**按名称列在其下方：收据保留其文件名（“B.TECH invoice 4471”），**编辑**可添加、重命名、替换与移除。它们属于该购买，因此在同一收据上购买的每件物品都会显示。添加在**文件**下的收据仅属于此物品并只在那里显示；同一文件两处都有时，购买下的会标注**也在文件中**，因此不算第二张收据。
- **操作**包含移动、借出、标签、拆分、复制、保存为模板、标记已见、不在此处、更改生命周期（已售出、已送出、已丢弃）、归档、更改类型、转换为房间或点位，以及移到回收站。
- **归档**适用于仍是你的、但已收起的物品：冬季轮胎、抽屉里的旧手机。与已售出的物品一样，它会离开在用物品列表并停止提醒，其页面显示**已归档**，旁有**取消归档**，一点即可恢复使用。用**已归档**筛选列表与搜索即可找到。两者都可撤销。
- **历史**列出每次更改及其操作者；大多数更改可从那里或随后的提示条撤销。菜单中的**活动**跨你的所有位置显示同样的内容。每次更改是一句话：“把 Galaxy S23 放到办公室的地图上”、“从照片拍摄了 Bosch 电钻，18 V”、“为 Home 生成了保险报告”。首次设置的字段会显示其值；地图整理中超过五次更改的会说明数量，**显示**可列出。

- **回收站**保留移入的物品 30 天；成员及以上可恢复，管理员可永久删除。
- **密码与代码**（完整预设）是机密字段：在获准的人揭示之前保持隐藏，揭示会被记录。

查看者看到同一页面，但除**复制链接**外没有其他操作。
