Kept 会提醒你：到期的计划任务、即将结束的保修与登记期限、即将过期的文档与物品、逾期的借出、近期未读取的仪表、低库存、成员加入与离开，以及 AI 花费上限。首页的**需要你处理**显示到期或逾期的事项；铃铛打开通知中心，其中的**完成**、**稍后**、**续期**与**标记已归还**可就地操作。

本页涵盖会到达你的内容、如何设置通道，以及按位置的设置。手机上的推送通知参见[手机上的 Kept](/zh/users/phone-app/#notifications)。

## 会到达你的内容

首页的**需要你处理**显示六个计数，位置固定不变：**已逾期**、**到期**、**即将到期**、**借出**、**不确定**与**库存偏低**。为零的项会置灰，而不是隐藏。**借入**与**很久未见**在有内容时才出现。电脑上每项还会显示最紧急的一条。点按可打开已筛选的列表。

通知中心（铃铛）按类型分组列出所有到期或逾期的事项。无需离开页面即可在那里**完成**、**稍后**、**续期**或**标记已归还**。

## 设置

**设置 → 我 → 通知**选择什么会到达你、以及如何到达：

- **每日摘要：**用一份每日汇总代替逐条通知。
- **免打扰时段：**在你设定的时段内不发通知。期间不推送也不发邮件；到期内容会等到时段结束再发送。
- **日历订阅源：**供你的日历应用使用的私密链接，显示到期日期。

手机上的推送见[手机上的 Kept](/zh/users/phone-app/#notifications)。

## 通知表

**会到达你的内容**是一张表。行为类型，分组如下：

- **到期日期：**计划任务、保修、登记期限、文档、即将过期的物品、近期未读取的仪表。
- **借出：**逾期的借出。
- **库存：**低库存。
- **人员：**成员加入与离开。
- **AI：**花费上限与每月汇总。

列为你的通道：

- **在 Kept 内：**通知中心与首页的需要你处理。
- **邮箱：**发到账户的邮箱地址。
- **推送：**发到你的手机（已配置推送时）。
- **Webhook / ntfy / Telegram / Apprise：**添加后，每种类型会多一列。

成员与 AI 相关通知只发到 Kept 与邮箱。把某类型的**在 Kept 内**关掉会同时关闭其他所有通道：不会再发送该类型。在手机上，每种类型会在下方把其通道显示为开关。

## 按位置的设置

- **全部位置**设定你在各处（包括以后添加的位置）收到什么。
- **选择某个位置**只更改那里的设置。圆点表示仅对该位置单独设定。
- **将此位置重置为全部位置**清除这些覆盖。
- 某处关闭了对应模块的类型会显示为已暂停（其提醒会等到模块恢复）。
- 你是查看者的位置，只会收到成员加入与离开。
- 你是成员的位置，Kept 默认只开启你记录的借出：按需开启其他类型。

## 设置通道

### ntfy

添加你的服务器（`https://ntfy.sh` 或你自己的）和一个不易猜到的主题，若主题需要再加访问令牌。Kept 会加密保存这些，且从不再次显示。**测试**会立即发送一条。

### Telegram

用 @BotFather 创建机器人，给它发一条消息，然后添加其令牌与你的聊天 ID。Kept 会加密保存这些，且从不再次显示。**测试**会立即发送一条。

### Apprise

当你的服务器装有 Apprise 时，粘贴一个或多个 Apprise URL（如 `discord://…`），即可到达 Discord、Slack、Matrix、Signal 等。Kept 会加密保存这些，且从不再次显示。**测试**会立即发送一条。

## 借出提醒

把物品（或数量的一部分）**借给**成员或联系人，可带到期日期与状况照片。Kept 从不给借用人发消息；**复制提醒**会给你可自行发送的文本。箱子会连同其内所有物品一起，每件一行。参见[套装与交接](/zh/users/kits/)。
