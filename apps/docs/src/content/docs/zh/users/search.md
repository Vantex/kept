搜索按名称、品牌、序列号、ID、位置，或 AI 添加为别名的词语查找物品，并把结果归组为物品、位置、人员、商店与文档（附收据文本摘录）。

本页涵盖可搜索的内容、筛选、已保存的搜索、离线搜索与语义搜索。

## 筛选

筛选按位置、场所、类型、标签与状态缩小结果。

**已保存的搜索**为你或整个位置保存一组筛选。

在电脑上，⌘K 或 Ctrl+K 可从任何地方打开搜索。

## 离线搜索

在手机上，搜索也可从手机的副本离线工作，标注为**本机，截至上次同步**。结果来自本地副本，你所做的更改会在恢复联网后同步。

## 语义搜索

连接了嵌入模型后，会加入“按含义匹配”的结果，与关键词结果并列。例如，关于裁纸的查询即使没有出现“剪刀”一词，也可能匹配到剪刀。参见 [AI 提供商](/zh/users/ai-providers/#search-and-embeddings)。

没有嵌入模型时，搜索只匹配名称与词语：“laptop”找不到 MacBook Pro。搜索会在结果上方显示**仅按名称搜索**，并附指向**设置 → AI** 的链接。助手与 MCP 客户端也会收到同样的信息（`search_things` 与 `where_is` 上的 `search_mode`），因此回答会说明仅按名称搜索，而不是说什么都不存在。

## 扫描

首页与搜索上的**扫描**会打开摄像头。一次扫描多个标签参见[扫描会话](/zh/users/scanning-sessions/)。

## 分享搜索

搜索上的**分享此列表**会为筛选到某一位置的搜索创建只读分享链接，不含状态或价格筛选。参见分享位置。
