## 可以试试

- **首页**：需要你处理的事。点某个计数即可打开已筛选的列表。
- 一个位置：它的房间以及里面有什么，直到箱子。**地图**以 3D 显示，**关系图**以图谱显示；首页在两层楼上，因此两者都以层显示楼层。
- 一件物品：它的单据、保修、历史和标签。
- **搜索**：名字的一部分，例如 `cable`。
- **标签**：没有印刷标签的物品，排在一张纸上。
- 侧栏中的**车辆**、**借出**、**即将到期**和**洞察**，手机上则是**更多**。

摄像头、麦克风、通知和应用锁在此处均已关闭。顶栏中的**重置**可恢复示例。要在你自己的服务器上运行 Kept，从[使用 Docker Compose 安装](/zh/install/compose/)开始。只要地图：[试用地图](/zh/try/map/)。
