## 可以试试

- 点一个房间、架子或箱子：卡片会说明它在哪里、里面有什么。**详情**有其余信息：类型和标签，部分物品有照片，以及标签的二维码。
- 地图下的**有什么**列出每个房间的物品。按名称或标签上的短 ID 查找，选择楼层，或切换到**需要关注**。编码仅在有印刷标签的物品上显示为琥珀色胶带。
- **平面**是俯视图。楼层按钮（**G**、**F**、**R**）上下切换；**全部**将它们堆叠。
- **库存不足**、**已借出**和**即将到期**可开关各自的图钉。
- **整理**：拖动物品，按住某房间的地板并拖到别处（里面的东西也跟着走），拖动琥珀色角调整房间大小，绘制房间。**放到…**可把小物件放到桌子或架子上。**完成**会保留到你离开页面，并提供**撤销**；**取消**会先询问。
- 关闭**精细模型**后，地图将不下载任何模型。

这就是 Kept 自带的地图，使用相同的模型。[位置地图](/zh/users/location-map/)解释了真实位置如何获得其楼层和房间。带示例家庭的完整应用：[试用 Kept](/zh/try/kept/)。要在你自己的服务器上运行 Kept，从[使用 Docker Compose 安装](/zh/install/compose/)开始。
